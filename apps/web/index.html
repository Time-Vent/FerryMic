使用说明

基础操作
  • 导入：把音频文件拖进窗口（或直接拖到左侧某个文件夹上），或点右上角「导入音效」。文件会保存进音效库文件夹。
  • 播放：点卡片即可播放；播放中拖动卡片底部的进度条可跳转，鼠标移到圆形按钮上点击可停止；右上角「全部停止」。
  • 卡片按钮：循环图标切换循环 / 单次（循环时再按一下卡片停止）；独占图标（一个圆点）/ 叠加图标（两个交叠的圆）切换播放时是否打断其它音效；音量点一下弹出竖向滑条；倍速点一下换一档（右键反向）。
  • 快捷键：点卡片右上角「⋯」打开编辑，点快捷键框后直接按组合键；其他程序全屏时也能触发。
  • 文件夹：左侧新建、重命名文件夹；把卡片拖到文件夹上即可移动。在资源管理器里改了文件后点左侧「刷新」。
  • 你的麦克风：底部左侧可静音、调音量、看电平；本页「音频链路」里选择设备（默认自动选硬件麦克风）。
  • 输出音频线路：底部右侧显示其他软件里该选哪个麦克风；本页「音频链路」里选择虚拟音频线。
  • 试听：混音输出到虚拟音频线后自己听不到，打开底部的耳机按钮，音效会同时在耳机里播放（不含你自己的声音）。
  • 手机遥控：左侧手机按钮一键开关，手机扫二维码即可打开同一界面。
  • 音效资源：左侧地球按钮收集了免费 / 开放的音效网站，也可以添加自己的网址；App 里点「预览」在窗口中打开，在那里下载的音频会自动存进音效库的「下载」文件夹。
各平台接入其他软件

Windows 当前系统

  1. 安装虚拟音频线，如 VB-Cable（免费）。
  2. 本页「音频链路 → 输出音频线路」选 CABLE Input。
  3. 其他软件的麦克风选 CABLE Output（底部右侧会提示）。
  4. 打开「试听」就能在耳机里听到自己放的音效。
  5. Windows「声音设置」里默认播放设备保持为耳机或扬声器，不要设成 CABLE Input，否则电脑播放的所有声音都会进麦克风。

Linux 当前系统

  1. 需要 PipeWire（含 pipewire-pulse）或 PulseAudio，以及 pactl 命令（pulseaudio-utils）。
  2. FerryMic 启动时自动创建虚拟麦克风 FerryMic-Microphone，退出时自动移除。
  3. 其他软件的麦克风选 FerryMic-Microphone。
  4. 全局快捷键需要 X11 会话（Wayland 下请改用 X11 会话，或用界面 / 手机遥控触发）。

macOS 当前系统

  1. 安装虚拟音频设备，如 BlackHole 2ch。
  2. 本页「音频链路 → 输出音频线路」选 BlackHole 2ch。
  3. 其他软件的麦克风选 BlackHole 2ch。首次使用需在「隐私与安全性」中允许麦克风权限。
