# ADR-0002：插件进程隔离策略

[English](../en/adr/0002-plugin-isolation.md) | **简体中文**

**状态**：预留 Proposed（第二阶段实现）

**日期**：2026-10-27

## 背景

第三方插件可能崩溃、死循环或恶意访问，不能让其影响宿主引擎进程。

## 决策

插件默认**进程隔离**（第二阶段）：

- C ABI 解决跨语言边界，**不解决崩溃隔离**——dylib 内崩溃会连带宿主。
- 桌面端：Process 隔离 + IPC 延迟补偿 + 超时回收。
- WASM 作为可选沙箱路径（移动端可行路径之一，但不是唯一）。
- 移动端插件走平台正规机制（iOS AUv3，系统托管强制独立进程）或内置 DSP。

## 约束

- Rust trait 不跨动态库边界；C ABI 必须版本化。
- 引入 Process 隔离时，必须同时引入 IPC 延迟补偿与超时回收。

## 后果

- 第一阶段只做第一方 InProcess 插件（gain/limiter 示例），隔离机制留待第二阶段。
