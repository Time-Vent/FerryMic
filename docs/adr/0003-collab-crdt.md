# ADR-0003：协作使用 CRDT，且与音频 PCM 严格分离

**状态**：预留 Proposed（只写 ADR，不实现）

**日期**：2026-10-27

## 背景

多人协作编辑需要同步数据，同时不能影响实时音频路径。

## 决策

三个问题的回答：

1. **协作对象**：预设、图结构、播放列表。不包括设备选择、独占资源、实时播放状态。
2. **输出归属**：每个参与者本地引擎独立输出；协作只同步参数与结构，不同步 PCM，
   不要求所有人听到同一路混音。「共享监听」为独立功能，单独评估。
3. **冲突规则**：参数用 CRDT 合并；设备选择、播放/停止由会话主持人单点决策，不进 CRDT。

## 约束

- Automerge 只在 bridge 层产出**已验证的 `EngineCommand`**，PCM 永不进入 CRDT。
- CRDT 文档与音频 PCM 永不交汇。

## 后果

- 第一阶段只保留 `collab/` 目录与 ADR，不写同步逻辑。
